# **DOCKER BASIC COMMANDS**

## **1. Building docker**

- docker build -t my-nginx .

             ↑

         name it "my-nginx"

Without -t your image gets a random ID like a1b2c3d4e5f6 — hard to remember. With -t my-nginx you can just type my-nginx everywhere.
